Une combustion

C'est une transformation chimique : un combustible réagit avec le dioxygène (le comburant). Il faut une source de chaleur pour la démarrer.

Les atomes se conservent

Les molécules des réactifs disparaissent, mais leurs atomes se réarrangent pour former les produits. Même nombre d'atomes de chaque sorte avant et après : la masse se conserve.

Les tests

Le dioxyde de carbone trouble l'eau de chaux. L'eau fait bleuir le sulfate de cuivre anhydre (blanc).
