Exercice 3. Le modèle de l'œil

Associe chaque partie de l'œil à l'élément qui la modélise.

Correction. L'iris règle la quantité de lumière qui entre : c'est un diaphragme. Le cristallin forme l'image : c'est une lentille convergente (de distance focale variable). La rétine reçoit l'image : c'est l'écran. Dans l'appareil photo, ce sont le diaphragme, l'objectif et le capteur.

Exercice 4. Œil ou appareil photo ?

On regarde un objet lointain, puis un objet proche. Pour que l'image reste nette :

a) Dans l'œil…

b) Dans l'appareil photo…

Correction. a) Dans l'œil, la distance cristallin–rétine est fixe (environ 17 mm) : pour un objet proche, le cristallin se bombe et sa distance focale diminue. C'est l'accommodation. b) La distance focale de l'objectif est fixe : pour un objet proche, l'image se forme plus loin derrière l'objectif, donc on éloigne l'objectif du capteur. C'est la mise au point. Vérifie-le avec les onglets « L'œil » et « L'appareil photo ».

Exercice 5. Œil myope, œil hypermétrope

a) Pour un œil myope qui n'accommode pas, l'image d'un objet très éloigné se forme…

b) Un œil myope voit flou…

c) On corrige un œil myope avec une lentille…

d) On corrige un œil hypermétrope avec une lentille…

Correction. a) L'œil myope est trop convergent (ou trop long) : l'image d'un objet éloigné se forme devant la rétine. b) Il voit donc flou les objets éloignés (mais net de près). c) On le corrige avec une lentille divergente, qui rend l'ensemble moins convergent. d) L'œil hypermétrope n'est pas assez convergent (ou trop court) : l'image se forme derrière la rétine, il voit flou de près. On le corrige avec une lentille convergente. Vérifie-le dans l'onglet « L'œil » en choisissant le type d'œil, puis en ajoutant une lentille dont tu règles la vergence.
