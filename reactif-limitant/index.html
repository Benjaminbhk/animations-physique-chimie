Quand on mélange des réactifs, la transformation s'arrête dès que l'un d'eux est épuisé : c'est le réactif limitant. Règle les quantités initiales, lance la transformation et observe les atomes se réorganiser, une réaction après l'autre.

3 À retenir

  • Le réactif limitant est le réactif entièrement consommé : quand il n'y en a plus, la transformation s'arrête. L'autre réactif est en excès : il en reste à l'état final.
  • Pour l'équation a A + b B → …, on compare n(A) / a et n(B) / b : le réactif qui a la plus petite valeur est le réactif limitant.
  • Attention : le réactif limitant n'est pas forcément celui qu'on a en plus petite quantité, il faut tenir compte des nombres stœchiométriques.
  • Si n(A) / a = n(B) / b, les deux réactifs sont entièrement consommés : le mélange est stœchiométrique.
  • Les atomes ne disparaissent pas, ils se réorganisent : c'est pour cela qu'on ajuste l'équation.
